# s1131501_林昱綸_BookListView README

## 專案名稱
BookListView 圖書清單管理系統

---

## 專案介紹
本專案使用 C# Windows Forms 開發，透過 `ListView` 控制項實作圖書清單顯示功能，使用者可以：

- 瀏覽書籍資料
- 切換不同檢視模式
- 查看書名、作者與類別
- 借閱書籍
- 防止重複借閱

此程式主要練習：

- ListView 控制項
- ComboBox 控制項
- ListBox 控制項
- 陣列資料管理
- 事件驅動程式設計

---

## 2. ListView 檢視模式切換
使用 `ComboBox` 可切換以下顯示方式：

| 模式 | 說明 |
|---|---|
| 大圖示 | LargeIcon |
| 詳細資料 | Details |
| 小圖示 | SmallIcon |
| 清單 | List |
| 大圖示加詳細資料 | Tile |

---

## 3. 借書功能
當使用者雙擊書籍時：

1. 取得目前選取的書名
2. 檢查是否已存在借閱清單
3. 顯示確認借閱視窗
4. 按下「Yes」後加入借閱清單
